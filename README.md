# موقع Uncoding — مع مساعد ذكاء اصطناعي

## الفكرة
- `index.html` هو الموقع نفسه (اللي يشوفه الزوار).
- `api/chat.js` هو "الحارس" اللي يستقبل رسائل الشات، يكلم Claude بالنيابة عن الموقع، ويحفظ مفتاح الـ API بأمان بعيد عن أي شخص يفتح مصدر الصفحة.
- كل زائر عنده حد أقصى **15 رسالة يومياً** (تقدر تغيّره من `DAILY_LIMIT` بملف `api/chat.js`).

---

## الخطوة 1: احصل على مفتاح API

1. روح [console.anthropic.com](https://console.anthropic.com) وسوّي حساب.
2. من قائمة **API Keys** أنشئ مفتاح جديد وانسخه (يبدأ بـ `sk-ant-...`).
3. لا تحط هذا المفتاح بأي مكان بالكود مباشرة — بس بمتغيرات البيئة (راح نوضح كيف).

---

## الخطوة 2: ارفع المشروع على GitHub

1. سوّي حساب على [github.com](https://github.com) إذا ما عندك.
2. أنشئ مستودع (Repository) جديد فاضي.
3. من جهازك، بمجلد المشروع:
   ```bash
   git init
   git add .
   git commit -m "أول نسخة من موقع Uncoding"
   git branch -M main
   git remote add origin <رابط-المستودع-اللي-سويته>
   git push -u origin main
   ```

---

## الخطوة 3: انشر على Vercel (مجاني)

1. روح [vercel.com](https://vercel.com) وسجّل دخول بحساب GitHub.
2. اضغط **Add New → Project**.
3. اختر المستودع اللي رفعته بالخطوة الماضية.
4. قبل ما تضغط Deploy، افتح قسم **Environment Variables** وضيف:
   - **Name:** `ANTHROPIC_API_KEY`
   - **Value:** المفتاح اللي نسخته من الخطوة 1
5. اضغط **Deploy**.
6. بعد دقيقة تقريباً، بيعطيك Vercel رابط مباشر لموقعك (مثل `uncoding.vercel.app`).

Vercel يكتشف مجلد `api/` تلقائياً ويشغّله كسيرفر — ما تحتاج تسوي شي إضافي.

---

## الخطوة 4 (اختياري): اربط دومين خاص بك

لو تبي الموقع يطلع باسم `uncoding.com` بدل `uncoding.vercel.app`:
1. من إعدادات المشروع بـ Vercel، افتح **Domains**.
2. ضيف الدومين اللي اشتريته (من أي مزود زي GoDaymon أو Namecheap).
3. Vercel بيعطيك سجلات DNS تحطها عند مزود الدومين — يتفعّل خلال ساعات قليلة عادة.

---

## تجربة الموقع محلياً قبل الرفع (اختياري، لو عندك خبرة بسيطة)

```bash
npm install -g vercel
vercel dev
```
هذا يشغّل الموقع والسيرفر محلياً على جهازك بنفس طريقة عمله بعد النشر.

---

## تعديلات تقدر تسويها بسهولة

| تبي تغيّر | وين تعدّل |
|---|---|
| نص المساعد وكيف يرد | `SYSTEM_PROMPT` بملف `api/chat.js` |
| عدد الرسائل المسموحة يومياً | `DAILY_LIMIT` بملف `api/chat.js` |
| ألوان وتصميم الموقع | داخل وسم `<style>` بملف `index.html` |
| نص وعناوين الموقع | داخل وسم `<body>` بملف `index.html` |

## ملاحظة عن الحد اليومي

النظام الحالي يحفظ عدد الرسائل بذاكرة السيرفر المؤقتة، وهذا كافي لموقع صغير أو متوسط. لو موقعك كبر وصار عنده زيارات كثيرة جداً، أفضل ترقية لاحقة هي ربط [Upstash Redis](https://upstash.com) (له باقة مجانية سخية) عشان الحد يكون دقيق ودائم حتى لو السيرفر أعاد التشغيل.
